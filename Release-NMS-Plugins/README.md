# Plugins

Perl plugin scripts shared by the quest files.

Drop these into your compiled server's `quests/plugins/` folder.

## Origin

These started from the [FVProject quest scripts](https://github.com/Gates-Of-Time/FVProject-Quests)
by the Gates of Time / Firiona Vie Project team, released under the MIT license, and have been
split out into their own repository, modified and extended for this server.

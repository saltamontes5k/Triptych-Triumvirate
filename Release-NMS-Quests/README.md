# Quests

Quest scripts (Perl and Lua) and plugins for the server.

Drop these into your compiled server's `quests/` folder.

## Origin

These started from the [FVProject quest scripts](https://github.com/Gates-Of-Time/FVProject-Quests)
by the Gates of Time / Firiona Vie Project team, released under the MIT license, and have been
modified and extended for this server. The original MIT notice is kept in `LICENSE`.
